## 第二周第五天：strace / lsof / ps 排查系统问题

### 1. strace 适合查什么问题？

`strace` 用来跟踪程序的系统调用。

它适合排查程序和操作系统交互相关的问题，比如：

- 打不开文件
- 找不到动态库
- 权限不足
- 网络连接失败
- read/write 行为异常
- 程序卡在某个系统调用上

例如程序提示 open failed，可以用 `strace` 看它到底尝试打开哪个路径，以及失败原因是什么。

### 2. openat ENOENT 是什么意思？

`openat` 是 Linux 打开文件的系统调用之一。

`ENOENT` 表示 No such file or directory，也就是文件或目录不存在。

例如：

`openat(AT_FDCWD, "not_exist.txt", O_RDONLY) = -1 ENOENT`

意思是程序尝试打开当前目录下的 `not_exist.txt`，但是这个文件不存在。

### 3. lsof 能解决什么问题？

`lsof` 可以查看哪些进程打开了哪些文件。

它常用于排查：

- 文件删不掉
- 目录卸载不了
- `.nfsxxxx` 文件占用
- 端口被哪个进程占用
- 某个进程打开了哪些动态库、日志文件或设备文件

常用命令：

`lsof | grep 文件名`

`lsof +D /path/to/dir`

`lsof -p <pid>`

### 4. .nfs 文件删不掉一般是什么原因？

`.nfsxxxx` 文件通常是 NFS 文件系统生成的临时文件。

一般原因是：某个进程还打开着原文件。即使用户执行了删除操作，NFS 也不能立刻真正删除它，于是把它改名成 `.nfsxxxx`。

等占用它的进程关闭文件或退出后，这个 `.nfsxxxx` 文件通常才会消失。

可以用：

`lsof | grep .nfs`

找到哪个进程还占用它。

### 5. ps -T -p pid 能看什么？

`ps -T -p <pid>` 可以查看某个进程里的线程。

它会显示该进程下的线程列表，包括线程 ID。

这在排查多线程程序时很有用，比如确认线程数量、查看线程是否还存在、把线程 ID 和 gdb/top/perf 里的信息对应起来。
