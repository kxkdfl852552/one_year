## 第二周第四天：动态库、链接、符号排查

### 1. 编译期链接和运行期找库有什么区别？

编译期链接是生成可执行文件时，链接器需要找到库和符号。

运行期找库是程序启动时，动态加载器需要找到 `.so` 文件。

编译时能找到库，不代表运行时也能找到库。

### 2. -L. 是什么意思？

`-L.` 表示把当前目录加入链接器的库搜索路径。

### 3. -lmath_ops 会找什么文件？

`-lmath_ops` 会查找名为 `libmath_ops.so` 或 `libmath_ops.a` 的库文件。

### 4. LD_LIBRARY_PATH 是干什么的？

`LD_LIBRARY_PATH` 用来指定程序运行时动态库搜索路径。

例如：

`LD_LIBRARY_PATH=. ./app`

表示运行 `app` 时，从当前目录找 `.so`。

### 5. ldd 能看什么？

`ldd` 可以查看可执行文件依赖哪些动态库，以及这些库实际解析到了哪个路径。

如果显示 `not found`，说明运行时找不到对应动态库。

### 6. nm -C 能看什么？

`nm` 可以查看目标文件、静态库、动态库里的符号。

`-C` 可以把 C++ 改写后的符号名还原成人能看懂的函数名。

### 7. undefined symbol 通常是什么原因？

常见原因包括：

- 声明了函数，但没有提供实现
- 编译时没有链接对应的库
- 链接了错误版本的库
- C++ 函数签名不一致
- 动态库运行时加载到了错误版本
- C 和 C++ 混用时没有处理 `extern "C"`
